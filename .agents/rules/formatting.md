# Quy định định dạng văn bản xuất ra

- TUYỆT ĐỐI KHÔNG sử dụng cú pháp LaTeX (ví dụ: `\frac`, `\mathbf`, `\sigma`, `\alpha`, `\approx`, `\times`, khối `$$...$$` hoặc inline `$..$`).
- Sử dụng văn bản thuần, ký tự Unicode chuẩn (ví dụ: alpha, beta, gamma, sigma, pi, độ (°), micro (µ), ±, x, /).
- Đối với công thức tính toán hoặc biểu thức toán học, trình bày dưới dạng chuẩn code/text trong cặp dấu backticks `...` hoặc khối code block để hiển thị chuẩn form, trực quan, không bị lỗi render.
